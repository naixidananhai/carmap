# 拼车路线优化系统算法详细设计 V1.0  
## （DBSCAN + 贪心初始解 + 2-opt + ALNS）

文档性质：

> 面向算法工程师的核心算法设计文档，定义拼车路线优化系统 V1.0 的求解流程、算法模块、评价函数、优化策略和工程实现边界。

适用范围：

- 单终点拼车
- 乘客规模：1～100人（V1重点30人）
- 车型：
  - 4人
  - 6人
- 硬约束：
  - 每人必须且只能分配一次
  - 车辆容量限制
  - 单车路线 ≤5400秒
- 优化目标：

第一目标：

> 总费用最低

第二目标：

> 总行驶时间最低

第三目标：

> 车辆数量最少


---

# 一、问题建模


该问题属于：

## Capacitated Vehicle Routing Problem with Time Constraint

简称：

CVRP-TW变体。


区别：

传统VRP：

车辆从仓库出发。


本系统：

车辆：

从第一个乘客点开始。


路线：

```
乘客A
 ↓
乘客B
 ↓
乘客C
 ↓
终点
```

# 合并评价

Route B


尝试：

Route AB


计算：

\[

接受。

# 九、Repair算子设计


## Greedy Insert


逐个插入。


寻找：

成本增加最小位置。


评价：


\[
\Delta C
\]


---

## Regret Insert


考虑：

未来损失。


公式：


\[
Regret=
Cost_2-Cost_1
\]


优先处理：

难插入乘客。


---

公式：


\[

\]


意义：

允许：

短暂变差。


避免：

局部最优。

# 十五、算法伪流程


```
function optimize(passengers):


  matrix = build_matrix()


  clusters = DBSCAN(passengers)


  solution = greedy_init(clusters)


  solution = two_opt(solution)


  best = solution


  while time < 300s:


      destroyed =
          destroy(solution)


      candidate =
          repair(destroyed)


      candidate =
          two_opt(candidate)


      if accept(candidate):

          solution=candidate


      if better(candidate,best):

          best=candidate



  return best

```
